# Product Roadmap

## Current MVP

- Study-plan, quiz, guidance, weekly-plan, and reading-summary endpoints
- Optional server-side AI assistance with safe fallbacks
- Responsive dashboard and automated API tests

## Next: usable personal app

- Persist courses, goals, and completed study sessions in a database
- Let users create, edit, and delete their courses and plans
- Show daily focus and progress from saved data
- Add clearer loading states and accessible form validation

## Then: multi-user app

- Add sign-up, sign-in, password reset, and protected routes
- Isolate each user's data and add authorization tests
- Add account deletion, privacy terms, and a retention policy
- Add rate limits, audit logging, monitoring, and backups

## Later enhancements

- Calendar and reminder integrations
- Study streaks and progress insights
- File upload with explicit privacy controls
- Instructor or tutor collaboration tools
